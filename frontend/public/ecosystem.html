Architecture note: This artifact demonstrates the full VARUNA user experience — master-agent orchestration, six specialized agents, collaborative evidence fusion, explainable risk assessment, GIS visualization, alerts, and a digital-twin what-if simulator — running client-side against realistic demo data, exactly as Demo Mode is meant to behave when live marine APIs are unavailable.
In the full system, this front end sits on a Python/FastAPI backend with dedicated agents/ (master, ocean, satellite, fisheries, coral, vessel, weather), a reasoning/ layer (evidence fusion, ecosystem reasoning, confidence engine), and an ml/ layer (time-series forecasting, XGBoost risk classification, Isolation Forest anomaly detection, LLM+RAG for the assistant). Data persists in PostgreSQL + PostGIS + pgvector, with Redis for agent-state caching, and the same REST contract used here (/query, /marine/conditions, /marine/risk, /marine/agents, /marine/agent-insights, /marine/evidence, /marine/alerts, /marine/predictions) is what this page would call once connected.
